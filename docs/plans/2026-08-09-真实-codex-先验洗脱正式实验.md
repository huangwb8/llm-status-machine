## 状态

技术与统计参数已在 25-episode exploratory pilot 后冻结。正式数据尚未生成；在明确批准 token/费用上限前保持停止。资格实验和 pilot 数据永久排除在正式分析之外。

## 研究问题

主要回答：

- 错误先验在获得独立验证证据后是否仍持续；
- 只保留公开证据 ledger 的门控是否比开放记忆降低错误先验持续；
- 完全清除前序状态是否比开放记忆降低错误先验持续。

主要 outcome 是 episode 级 IFO-AUC，方向为越低越好。三个主要 contrasts 是：

- `false-open-v-neutral-open`；
- `false-gated-v-false-open`；
- `false-purged-v-false-open`。

三个 contrasts 属于同一个 primary family，使用 Holm 校正。所有随机分配的 episode 都进入 intention-to-treat 分析。

## 样本量冻结

MDE 在查看 pilot treatment effect 前固定为 IFO-AUC 原始绝对差 0.25。三个主要 contrasts 使用双侧 `alpha=0.05/3`，power 为 0.80。

25-episode pilot 的 pooled within-arm SD 为 0.182447，20 个自由度下单侧 95% 上界为 0.247697。按预注册公式：

```text
sigma_used = max(0.30, 0.247697) = 0.30
```

两独立等样本臂近似要求 31 episode/臂。为保证五臂在 sequence position 1–5 上平衡，向五的倍数上取整为 35 episode/臂：

```text
35 × 5 = 175 episodes
175 × 3 = 525 Codex processes
```

该规模低于事前资源上限 50 episode/臂、250 episode total。

## Pilot 成本证据与启动门禁

pilot 实测 25 episode、74 个完成 stage：

- input tokens：2,108,364；其中 cached input tokens：859,136；
- output tokens：160,251；
- episode 墙钟中位数：169.76 秒；p90：233.91 秒；最大值：1,033.16 秒；
- 24 completed、1 timeout-failed；25 个 seal 全部有效。

按 175/25=7 倍线性外推，正式运行中心估计约 14.76M input tokens 和 1.12M output tokens。启动门禁使用 1.2 倍余量：最多约 17.71M input tokens、1.35M output tokens。由于当前 provider 没有可审计的单价，必须由用户显式批准该 token 上限或给出更低的停止阈值后才能启动。

## 停止与分析规则

- 不按 arm、候选质量、临时 effect 或 p 值提前停止；运行期间不做解盲推断。
- 仅在达到获批的累计 token/费用上限、外部鉴权失效、runtime digest 漂移、凭据边界失败或 seal 损坏时安全停止。
- 正常 episode 失败不触发替换或重试，按最坏值进入数据集。
- 完成后先验证全部 seal，再执行每 episode 两次 blind symbolic scoring；一致性、缺失和 scorer 错误必须进入报告。
- dataset 必须一行一个 episode，固定 175 行；按预注册三个 contrasts 做随机化检验、bootstrap 区间和 Holm 校正。
- 任一确认性门禁失效时只输出事实数据并降级为 descriptive，不宣称回答主要研究问题。
